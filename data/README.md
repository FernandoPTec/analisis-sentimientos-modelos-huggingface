# Data

El conjunto de datos utilizado en este proyecto es **Amazon Polarity**, disponible en Hugging Face mediante el identificador:

`mteb/amazon_polarity`

Los datos se descargan directamente mediante la librería `datasets`. Para garantizar la reproducibilidad, se utiliza la partición `test`, una muestra de 1,000 reseñas y la semilla `42`.

El conjunto de datos no se almacena directamente en este repositorio.
